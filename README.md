# mini-python-code
A collection of beginner-friendly Python mini projects — 🎲 Dice Roller, 🔢 Number Guessing Game, 🪨 Rock-Paper-Scissors, and 📷 QR Code Generator.
This repository contains a set of small Python programs created for practice and learning:

- 🎲 **Dice Roller** – Simulates rolling dice with random outcomes.
- 🔢 **Number Guessing Game** – Try to guess the number chosen by the computer.
- 🪨 **Rock-Paper-Scissors** – Classic hand game against the computer.
- 📷 **QR Code Generator** – Create QR codes from text or links.
- 🟩 **Rock,paper,scissior** - Play rock,paper and scissior

## How to Run
Clone the repository and run each program with Python:
```bash
python dice.py
python number guess.py
python rps.py
python qr_generator.py
python rock_paper_scisior.py
